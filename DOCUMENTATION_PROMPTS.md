# Documentation Prompts for AI Coder Agent

## Creating and Maintaining Documentation - Ready-to-Use Prompts

### 1. API Documentation Creation

**Prompt:**
```
Context: Creating comprehensive API documentation for [SERVICE/API_NAME].
Task: Generate complete API documentation with examples and usage guidelines.
Documentation Requirements:
- Overview and purpose of the API
- Authentication and authorization methods
- Complete endpoint reference with HTTP methods
- Request/response schemas with examples
- Error codes and error handling guidance
- Rate limiting and usage quotas
- SDK examples in multiple languages
- Postman collection and testing guide
- Integration examples and best practices
- Changelog and version information
Expected Deliverable: Complete API documentation site with interactive examples and code samples.
Quality Checks: Accurate and up-to-date, includes all endpoints, examples are working, easy to understand.
```
